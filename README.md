# 听澜 2

新站点，和根目录的旧版完全独立：旧站在 `/`，新版在 `/chat-v2/`，数据互不影响（新版用独立数据库 `tinglan2`）。

## 已完成

### 阶段 1 · 骨架
- 多对话：新建、切换、重命名、删除
- 流式输出、停止生成（保留已写出的部分）
- 深度思考：先展示思考链，出正文后折叠为「已深度思考 · 用时 N 秒」
- Markdown：粗体、斜体动作、行内代码、代码块
- 手机适配、深色模式、IndexedDB 本地存储、人话错误提示

### 阶段 2 · 角色扮演层
- 三张卡：AI 角色、我的角色、故事背景（顶栏 🎭）
- 三层提示词：行为准则（铁律）+ 人设 + 文体（写作预设），结尾再重申三条硬规则
- 写作预设：内置「角色扮演 / 小说创作」，可新建、改名、删除，切换即生效
- 行为准则：可编辑，可一键恢复默认
- 角色模板库：保存 / 载入 / 删除

### 阶段 3 · 分支
- `‹ 2/3 ›` 版本切换，切换后下面的剧情跟着换
- 重抽：再生成一个版本，旧版本永远保留
- 从这里继续：回到任意一条回复的时间点开新分支
- `↩ 最新`：正在看旧分支时，一键回到最新一条

### 阶段 4 · 周边
- **修改我的消息**：改完自动作为新分支，原来的消息和后续剧情都保留
- **导出**：当前时间线导出 TXT / Markdown；JSON 包含整棵分支树
- **备份 / 恢复**：一个文件带走全部对话、角色模板、预设、行为准则（背景图不含）
- **角色主动性**：沉默一段时间后角色主动说话，可设间隔、暂停时段、最多连说几句
- **聊天背景**：本地图片，可调透明度和模糊（图片存在 IndexedDB，不占 localStorage）
- **搜索**：按标题或对话内容搜索，显示命中片段
- **置顶**：对话可置顶，排在列表最前
- **PWA**：可安装到手机桌面，离线也能打开界面（API 仍需联网）

## 怎么部署

1. GitHub 仓库首页 → **Add file → Upload files**
2. 把整个 `chat-v2` 文件夹拖进去（会保留 `js/` 子目录，包含新增的 `manifest.json`、`sw.js`、图标）
3. 提交，等一两分钟
4. 访问 `https://你的用户名.github.io/仓库名/chat-v2/`

更新版本后请 **Ctrl+F5 强制刷新** 一次。

## 装到手机桌面

用手机浏览器打开站点 → 菜单 → 「添加到主屏幕 / 安装应用」。装好后从桌面图标进入，没有地址栏，接近原生 App。

## 数据说明

- API Key、预设、行为准则、主动性设置：`localStorage`（`tl2_` 前缀）
- 对话、消息、角色模板、背景图：`IndexedDB` 的 `tinglan2` 数据库
- 清浏览器数据 / 换设备 / 换域名，数据都不会跟着走
- 备份文件包含对话、消息、模板、预设、行为准则；**不包含背景图**
- 旧站的数据完全不受影响
